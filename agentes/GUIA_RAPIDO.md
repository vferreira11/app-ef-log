# 🚀 SISTEMA DE AGENTES - GUIA RÁPIDO

## ⚡ Como Usar

### 1. **Ativação Simples**
```
@frontend otimize a landing page
@backend crie uma API REST para usuários  
@ia implemente um modelo de classificação
@security audite a aplicação
@devops configure CI/CD
```

### 2. **Comandos Naturais**
```
Ative o frontend expert e melhore a UX do dashboard
Preciso do especialista backend para otimizar as queries
@ia analise este dataset e sugira melhorias
```

### 3. **Contexto Incremental**
```
@frontend         # Agente ativado
Agora otimize também o header
E adicione lazy loading nas imagens
Crie um PR com todas as mudanças
# Agente permanece ativo durante toda conversa
```

| Trigger | Agente | Especialidade | Emoji |
|---------|--------|---------------|-------|
| `@frontend` | Frontend Expert | UI/UX, React, Performance | 🎨 |
| `@backend` | Backend Expert | APIs, Database, Arquitetura | 🔧 |

## 📝 O que os Agentes Fazem Automaticamente

### ✅ **Análise Automática**
- Leem arquivos relevantes do projeto
- Identificam padrões e estruturas
- Avaliam o contexto específico

### ✅ **Implementação Direta**
- Criam branches automaticamente
- Implementam mudanças nos arquivos
- Seguem best practices da área

### ✅ **Pull Requests**
- Criam PRs com descrições detalhadas
- Adicionam labels apropriados
- Incluem checklists de validação

### ✅ **Continuidade**
- Mantêm contexto durante a conversa
- Lembram de decisões anteriores
- Acumulam conhecimento incremental

## 💡 Exemplos Práticos

### **Cenário 1: Desenvolvimento Full-Stack**
```
@frontend crie uma tela de login responsiva
# Frontend expert cria componente React + CSS

@backend agora crie a API de autenticação  
# Backend expert implementa JWT + endpoints

@security revise a segurança da autenticação
# Security expert audita e melhora segurança
```

### **Cenário 2: Data Science**
```
@ia analise este CSV de vendas
# IA specialist faz EDA completa

Agora crie um modelo preditivo
# Continua como IA specialist, implementa ML

@devops configure deploy do modelo
# DevOps expert cria pipeline MLOps
```

### **Cenário 3: Otimização**
```
@devops analise a performance da aplicação
# DevOps expert monitora métricas

@frontend otimize o frontend baseado nos dados
# Frontend expert implementa melhorias

@backend otimize as queries do database
# Backend expert melhora performance DB
```

## 🔧 Configuração

O sistema está configurado em:
- `/agentes/config/sistema_agentes.json` - Configurações
- `/agentes/config/copilot_instructions.md` - Instruções
- `/agentes/personas/*.md` - Personas dos agentes

**Não requer instalação ou setup adicional!**
Funciona nativamente no GitHub Copilot.
