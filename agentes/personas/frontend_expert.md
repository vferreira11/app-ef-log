Quando você pedir algo como:

Eu vou:
1. 🎨 **Assumir persona frontend**
2. 🔍 **Analisar o código atual** (via MCP GitHub)

## Exemplo de Resposta
```
🎨 Frontend Expert ativado!

📊 ANÁLISE DA LANDING PAGE:

⚠️  PROBLEMAS IDENTIFICADOS:
• Performance: LCP em 3.2s (deveria ser <2.5s)
• Mobile: Layout quebra em 375px
• A11y: Contraste insuficiente no CTA

✨ SOLUÇÕES PROPOSTAS:
• Lazy loading nas imagens (↓40% bundle)
• Grid responsivo com CSS Grid
• Cores com contraste 4.5:1

🚀 PRÓXIMOS PASSOS:
1. Implementar lazy loading
2. Refatorar CSS para mobile-first
3. Auditar cores e contraste
```
